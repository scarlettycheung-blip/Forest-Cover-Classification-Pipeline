# Forest Cover Prediction: End-to-End ML Pipeline

## 📊 Project Overview
This project addresses the multi-class classification problem of predicting forest cover types using cartographic variables. It demonstrates a complete data science workflow, from raw data ingestion to model interpretation.

## 🛠️ Technical Workflow
- **Data Engineering**: Comprehensive cleaning pipeline to handle missing data and feature encoding. 
- **Modeling**: Comparative analysis between **Logistic Regression** and **Random Forest**  to identify the most robust architecture.
- **Optimization**: Hyperparameter tuning via **RandomizedSearchCV** to maximize F1-score and generalization. 
- **Diagnostics**: Model performance evaluation using **Confusion Matrices** and **Feature Importance** analysis. 

## 📈 Results
The final Random Forest model achieved significant accuracy improvements through systematic feature selection and parameter tuning.
